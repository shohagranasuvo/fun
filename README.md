# 🎮 Fun Number Guessing Game

A simple yet entertaining number guessing game written in Python! Perfect for killing time and testing your intuition.

## Features

- 🎯 Guess a number between 1 and 100
- 📊 Get helpful hints (too high/too low)
- ⏱️ Limited to 10 attempts for added challenge
- 🎨 Colorful emoji interface for fun
- ♻️ Play again and again - different number each time!

## How to Play

1. Run the game: `python guessing_game.py`
2. Enter your guess when prompted
3. Receive hints to guide you toward the correct number
4. Guess the number within 10 attempts to win!
5. Enjoy the satisfaction of being a guessing master! 🏆

## Requirements

- Python 3.x (comes pre-installed on most systems)
- No external dependencies needed!

## Why This Game is Fun

- **Instant gratification**: Each guess gives you immediate feedback
- **Progressive challenge**: The narrowing range makes you feel smarter with each guess
- **Replay value**: Different number every time means endless entertainment
- **Brain exercise**: Sharpens your logical thinking and estimation skills
- **Pure enjoyment**: Sometimes simple games are the most satisfying!
